🔬 Luxury Laboratory
An Interactive Web Application for Logic Games, Formula Development, and Clinical Laboratory Management

🌟 Overview
Luxury Laboratory is an advanced web application that combines logical challenges, real-time chemical formula development, and a personal user management system. Designed with a prestigious and meticulous clinical laboratory atmosphere, the project offers a dynamic, intuitive, and engaging user interface.

🛠 Technologies Behind the Project
HTML5: Site structure and interface elements.

CSS3: Advanced styling, custom animations (keyframes), and luxury glassmorphism effects.

Vanilla JavaScript (ES6+): Game logic management, keyboard and mouse event handling, and user data management.

🚀 Key System Features
Personal User and Security System:

Secure login and registration screens.

Advanced data persistence using LocalStorage, enabling personal tracking of each user's total games played and success records.

The Pharmaceutical Laboratory (Trivia and General Knowledge Game):

Progressive leveling stages (Alpha, Beta, and Gamma formulas).

Visual test tube simulation that gradually fills up as correct answers are provided.

A life system accompanied by dynamic success or explosion animations.

Real-Time Chemical Development (Typing Game):

Challenge of writing complex chemical formulas under time constraints.

Tiered difficulty levels matching the laboratory development ranks.

Full on-screen virtual keyboard (letters, numbers, plus sign, and arrows).

Full Physical Keyboard Support: Smooth recognition of letters, numbers, and plus/equals keys (including Shift combinations).

📊 Laboratory Ranks and Hierarchy
Junior Lab Assistant: Basic entry-level stage for learning fundamentals and initial laboratory practice.

Senior Researcher: Advanced stage involving independent development and cracking complex formulas under pressure.

Molecular Architect: The professional pinnacle, indicating absolute mastery over substances and their structures.
